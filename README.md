# Smart Home Energy Consumption Data Cleaning and Analysis

## Project Overview
This project focuses on cleaning and analyzing smart home energy consumption data combined with weather information using Python.

## Objectives
- Load and inspect the dataset.
- Identify missing values and duplicate records.
- Clean column names and data types.
- Process timestamp data.
- Handle missing numerical and categorical values.
- Create time-based features.
- Visualize energy consumption patterns.
- Export the cleaned dataset for further analysis.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- GitHub

## Dataset
**Dataset:** Smart Home Dataset with Weather Information

**Source:** Kaggle

https://www.kaggle.com/datasets/taranvee/smart-home-dataset-with-weather-information

## Project Workflow
1. Import Python libraries.
2. Load the dataset.
3. Explore rows, columns, and data types.
4. Check missing values.
5. Remove duplicate records.
6. Clean blank values.
7. Convert timestamps into datetime format.
8. Convert measurement columns into numeric format.
9. Handle missing values.
10. Create hour, day, month, and weekday features.
11. Check statistical summaries and negative values.
12. Save the cleaned dataset.
13. Visualize energy consumption over time.

## How to Run
1. Open Google Colab.
2. Upload or open `HomeC_cleaning.ipynb`.
3. Run the notebook cells in order.
4. Download the generated `HomeC_cleaned.csv` file.

## Expected Output
- Cleaned energy consumption dataset.
- Missing-value and duplicate-value reports.
- Numerical statistical summaries.
- Time-based features.
- Energy consumption visualization.
